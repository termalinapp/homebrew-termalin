# Termalin Homebrew tap

[Termalin](https://termal.in) is a cross-platform SSH client with a built-in MCP
server — so AI agents can run commands over SSH without ever holding your keys.
Key custodian, per-host command policy, a live watch-grid of every session, and
an audit log. Windows, macOS, Linux.

## Install (macOS)

```sh
brew tap termalinapp/termalin
brew install --cask termalin
```

Or in one line:

```sh
brew install --cask termalinapp/termalin/termalin
```

This installs the signed, notarized macOS build from
[termal.in/download](https://termal.in/download). The Free tier has no host
limits.
